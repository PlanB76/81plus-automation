## 1. QUADRO NORMATIVO DI RIFERIMENTO

La ripartizione tra **E-Learning (FAD asincrono)** e **Aula / Presenza Fisica** è regolata da:
1. **D.Lgs. 81/2008** (Testo Unico sulla Sicurezza sul Lavoro, in particolare art. 34, 37, 73, 77).
2. **Accordo Stato-Regioni 21/12/2011** (Formazione dei lavoratori, dirigenti, preposti e datori di lavoro/RSPP).
3. **Accordo Stato-Regioni 22/02/2012** (Abilitazione all'uso delle attrezzature di lavoro con addestramento pratico).
4. **Accordo Stato-Regioni 07/07/2016** (Requisiti per la formazione e-learning e riconoscimento dei crediti formativi).
5. **Legge 215/2021** (Modifiche urgenti all'art. 37 in materia di preposti e datori di lavoro).
6. **Nuovo Accordo Unico Stato-Regioni 2024/2025** (Riordino e armonizzazione di tutta la formazione sulla sicurezza).
7. **D.M. 02/09/2021** (Decreto GSA — Criteri per la gestione dei luoghi di lavoro ed emergenza antincendio).
8. **D.M. 388/2003** (Regolamento recante disposizioni sul pronto soccorso aziendale).

## 3. LOGICA DI ROUTING AUTOMATICO NEL `delivery81_router.py`

Il router didattico applica la seguente logica deterministica:

```python
def determine_delivery_mode(corso_code, ateco_macro):
    # Regola 1: Corsi con componente pratica obbligatoria per legge
    if any(k in corso_code for k in ["MULETTO", "CARRELLI", "PLE", "GRU", "TRATTORI", "ESCAVATORI", "ANTINCENDIO", "PRIMOSOCCORSO", "QUOTA_DPI"]):
        return {
            "mode": "BLENDED" if "ANTINCENDIO" in corso_code or "MULETTO" in corso_code else "AULA_PRESENZA",
            "backend_platform": "ANFOS_CENTRI",
            "centro_code": "RO/3",
            "logistica": "Sessione pratica in presenza certificata tramite Centro ANFOS RO/3 con emissione attestato QR Code",
            "margin_tier": "ALTO (80% - 93%)"
        }
        
    # Regola 2: Formazione Specifica Edilizia / Manifattura (Rischio Alto)
    if ateco_macro == "EDILIZIA" and "SPEC" in corso_code and "AGGIORN" not in corso_code:
        return {
            "mode": "AULA_PRESENZA",
            "backend_platform": "ANFOS_CENTRI",
            "centro_code": "RO/3",
            "logistica": "Aula in presenza o videoconferenza sincrona interattiva a norma D.Lgs. 81/08",
            "margin_tier": "ALTO (85%)"
        }
        
    # Regola 3: Documenti (POS, DVR, HACCP)
    if "DOC_" in corso_code or "POS" in corso_code:
        return {
            "mode": "DOCUMENTALE",
            "backend_platform": "81PLUS_INTERNAL",
            "logistica": "Generazione guidata immediata online con download PDF",
            "margin_tier": "MASSIMO (100%)"
        }
        
    # Regola 4: Default 100% E-Learning FAD Asincrono (Generale, Rischio Basso, Aggiornamenti quinquennali, Dirigenti, HACCP)
    return {
        "mode": "ONLINE_FAD",
        "backend_platform": "FAD_PID_2377",
        "logistica": "Fruizione e-learning asincrona 24/7 con tracciamento SCORM certificato",
        "margin_tier": "MEDIO (72% - 76%)"
    }
```
